# 反常光谱 · EP16

基于用户提供的《主题曲「反常光谱」EP16.mp4》制作的非官方交互展示。

## 运行

直接打开 `dist/index.html`，或在当前文件夹运行 `node serve.cjs`，再访问 `http://localhost:4178`。

使用原生 HTML、CSS、JavaScript，无需安装依赖。中文衬线字体可联网加载，离线时自动使用系统字体。视频及所有画面资源均保存在本地。

## 内容与交互

- 三组原片截图，可点击或使用方向键切换。
- 极夜区局部路线：16-12 至 16-16，以及 EG-7。支持类型筛选、节点选择和原片定位。
- 三个影像档案卡片，点击后跳转至视频时间点。
- 沿途的脚印、人道援助入口详情。
- 原片播放器、片段快捷跳转、Escape 关闭、焦点管理与减少动态效果支持。
- 桌面和移动布局，窄屏路线支持横向滚动。

素材时长约 182 秒。场景标题为画面描述，路线仅作浏览演示；不提供真实游戏交互，不推断未确认的剧情、角色名或奖励机制。原片中的活动日期、资源与进度不作为实时状态。

文件：`dist/index.html`、`dist/styles.css`、`dist/app.js`、`dist/assets/`。
